## 🧠 Suggestions d'Amélioration

### 🔴 Priorité Haute

#### 1. **Convention Nommage BDD** ⚠️
**Problème** : Mélange `status` (anglais) et `statut` (français) dans le code
**Impact** : Tests qui échouent silencieusement, confusion
**Solution** :
```php
// Créer une constante dans Order.php
const STATUT_PAYEE = 'payee';
const STATUT_EN_ATTENTE = 'en_attente';
// etc.

// Et interdire 'status' via PHPStan ou règle projet
```

#### 2. **Factory States Standardisés**
**Problème** : Répétition de `['statut' => 'payee']` dans les tests
**Solution** :
```php
// Dans OrderFactory.php
public function paid() {
    return $this->state(['statut' => 'payee']);
}

// Usage dans tests
Order::factory()->paid()->create();
```

#### 3. **Test Speed** 🏎️
**Actuel** : ~3-4 secondes pour les tests Feature
**Objectif** : <2 secondes
**Actions** :
- Lazy RefreshDatabase (une seule fois par classe)
- Réutilisation de factories entre tests
- SQLite :memory: déjà activé ✅
